# Design Pillars

**Status: ✅ LOCKED**

Links back to [[Home]].

Every feature, mechanic, UI screen, and art asset gets tested against these 5 pillars. If it doesn't serve at least one, cut it.

1. **Passive Income Drives Progression** — The game must reward you for *not* playing. Idle earnings unlock new content, powers, heroes. Tapping accelerates, but walking away should always feel productive.

2. **Pixel Art, Fast Iteration** — Every asset must be producible in <2 hours by a 1–2 person art team. Use palette constraints (16–32 color max), sprite sheets, procedural variation. No hand-painting, no bloat.

3. **Roguelike Runs = Replayability** — Short strategic runs (5–10 min) with decisions (pick a hero, manage health/resources, choose abilities) make every session feel fresh. Runs reward the main progression but are not *required* to advance.

4. **One-Hand Thumb Control** — MVP focuses on tapping and swiping only. No complicated gestures. Game works in portrait mode (vertical phone screen, thumb reach = reachable). UI centered around active area.

5. **Instant, Visible Feedback** — Every tap triggers a number pop (+$), animation, or sound. Passive income displays continuously ($/sec counter). Players always know "am I progressing?". Satisfying is non-negotiable.
